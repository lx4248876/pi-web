改动理解：会话侧栏可一键复制「会话ID」

Standard 生成于 2026-08-18；基于仓库只读核实。

提示：涉及「会话」属于高风险词范畴，本改动只新增一个复制按钮，不改动任何会话创建/读取/删除逻辑本身；因与「会话」相关故按 Standard 档交付更强的理解材料。

一句话

在左侧会话列表每个会话行的悬停操作区，加一个「复制会话ID」按钮，点击后把该会话的唯一ID复制到剪贴板，方便用户粘贴转发给排查方（比如我）。

改动地图

components/SessionSidebar.tsx · SessionItem — 会话单行组件，含悬停时的操作按钮（重命名/删除等）
怎么改 / 为什么

在 SessionItem 的悬停操作按钮区内，紧挨现有按钮加一个复制图标按钮，点击时把 session.id 写入剪贴板并给个已复制反馈（如短暂变色/标题）。为什么落这：这里已聚集了会话行的所有典型操作，用户目光和交互习惯都在这儿；且每行已持有当前 session，无需再查 ID。

components/SessionSidebar.tsx · copy 文本工具函数（新增局部函数）
怎么改 / 为什么

在文件内补一个几十行的复制小工具（navigator.clipboard.writeText，失败回退到隐藏 textarea + execCommand("copy")），和 MessageView.tsx 里已有的 copyText 同款实现。为什么不在别处改：MessageView.tsx 的 copyText 未导出，跨文件引用耦合重，不如在 SessionSidebar 本地自带一份，改动更内聚。

components/MessageView.tsx · copyText — 现有复制实现（本次不改，仅作参照）
波及说明

只读参照，无需改动；避免为复用而改它的导出签名，扩大影响面。

逻辑链路

用户悬停会话行 → 显示操作按钮（含新的复制图标） → 点击复制 → 本地工具函数写剪贴板 → 剪贴板得到该会话ID，供粘贴转发

改完你应看到

  • 鼠标悬停在任一会话行时，右侧操作区出现复制图标按钮。
  • 点击后系统剪贴板里就是该会话的完整 sessionId；粘到聊天框/文档可确认。
  • 按钮有轻微点击反馈（颜色变化或标题文字切换为「已复制」）。
  • 会话行的选中/重命名/删除/折叠等既有行为完全不受影响。

先别动

  • 不改 MessageView.tsx 的 copyText 导出与调用。
  • 不改会话的后端 API / RPC 管理（lib/rpc-manager.ts 等）与任何会话增删改逻辑。
  • 不改动作按钮的布局与尺寸体系（沿用现有 32×32、边线、悬停配色）。
  • 不做全局「复制当前会话ID」等其他快捷入口，本条仅覆盖每行一个按钮。

未知与假设

  • 未知：浏览器为 http（非 localhost 白名单）环境下 navigator.clipboard 是否可用；已有回退方案覆盖。
  • 假设：用户更希望在每行按钮里复制局部ID，而非在页面头/URL 隐藏处放全局复制。
  • 材料：够（SessionItem 结构、现有复制工具、hover 按钮区均已定位核实）。
