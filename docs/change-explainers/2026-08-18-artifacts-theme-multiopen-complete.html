交付讲解：产物横条增强

已完成 生成于 2026-08-18；基于真实 diff 与页面验收。

一句话结论

① 文件查看器里预览 HTML 时，现在会跟随 web 页面的明暗主题：切深色模式，没写背景色的 HTML 预览也变深底浅字。② 点产物横条里任意一个文件，会把这一轮的其它产物也一起在文件查看器里开成标签页，标签栏直接切换；范围限当轮，不越开越乱。

生活类比

① 像把打印好的页面放进「深色灯箱」看——纸没有自己颜色时，灯箱是什么色它就显什么色；纸自己印了颜色，印的优先。② 像一次把这一单的几个附件都摊开在工作台上切成标签页，哪个都能随手翻到，而不是一次只递你一张纸、再看下一张得回去翻。

动了哪几块

lib/html-preview-theme.ts（新增）— 主题注入器

纯函数 applyPreviewTheme(html, isDark)：往预览 HTML 里塞一段低优先级样式，写 color-scheme 与默认底色/文字色；文件自己写了样式就覆盖它。

lib/artifacts.ts（扩充）— 开启顺序

加 orderedArtifactOpen(artifacts, activePath)：把点中的那个排到最后，让它在标签栏保持激活。

components/FileViewer.tsx（改动）— HTML 预览接入主题

预览 iframe 的 srcdoc 改由 applyPreviewTheme(content, isDark) 生成；isDark 切了预览跟着变。

components/ArtifactStrip.tsx（改动）— 点一个开整轮

chip 点击从「只开这一个」改成「按 orderedArtifactOpen 把该轮全部产物逐个开成标签，点中的最后开(激活)」。

怎么测（你也能验证）

1. 深色模式下打开一个没写背景色的 HTML 文件（文件查看器 → Preview）→ 预览是深底浅字；切回浅色变白底黑字。
2. 在一轮写了多个文件的会话里，点产物横条任一个文件名 → 文件查看器标签栏一次出现该轮全部文件，想切哪个切哪个，当前激活的是你点的那个。
3. 只读/问答轮没有横条。
