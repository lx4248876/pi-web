改动理解：产物横条增强（主题跟随 + 当轮多开）

Standard 生成于 2026-08-18；基于仓库当前只读核实。这是对刚交付的「每轮产物横条」的叠加增强，基线讲解页见 2026-08-18-artifacts-strip(-complete).html。

一句话

两条互不相关的小增强：① 文件查看器里预览 HTML 文件时跟随 web 页面的明暗主题；② 产物横条点任一文件时，把「当前这一轮」的其它产物也一起开成标签页，在标签栏切换，范围限定当轮、不无限累计。

改动地图

改动Acomponents/FileViewer.tsx · HTML 预览主题

让没有自带明暗色的 HTML 文件预览跟随 web 页面主题。

怎么改 / 为什么

现有 HTML 预览用 iframe srcDoc={content}，内嵌文档没有主题信息，短 HTML 永远白底黑字。改动：渲染预览时，把 web 页面当前主题对应的 color-scheme 与基础背景/文字色一并注入到 srcDoc（低优先级，文件自带样式仍优先生效）。此时组件里已有 useTheme() 的 isDark，切主题会重新计算注入、实时跟随。文件自己写了背景/文字的，会照旧用自己的样式，不受影响。

改动Bcomponents/ArtifactStrip.tsx · 当轮多开

点横条任一个文件 → 把该轮所有产物一起开成标签页，点中的那个保持激活。

怎么改 / 为什么

横条已持有当前轮的 artifacts[] 与 onOpenFile。改 chip 的 click：不再只开点中的那个，而是把当前轮的去重文件逐个开成标签（复用现有 onOpenFile → AppShell.handleOpenFile，它本身按文件路径去重，不会重复），并把点中的那个作为最后一个处理，使其在标签栏成为当前激活页。范围就是这一轮的几个文件，不跨轮累计；其它轮的横条各自独立。纯 ArtifactStrip.tsx 单点改动，不动 AppShell / ChatWindow。

逻辑链路

改动A：打开 HTML 文件→切到 Preview→按当前 isDark 注入 color-scheme/底色文字→预览跟随主题，切主题实时变
改动B：点产物横条一个文件→逐个 openFile(该轮全部去重文件)→点中的最后处理 = 激活→文件查看器多标签页，随便切换

改完你应看到

  • （改动A）深色模式下看一个没写背景色的 HTML，预览是深底浅字；切到浅色变白底黑字。
  • （改动B）点横条上一个产物，文件查看器标签栏一次出现该轮全部的产物文件，想切哪个切哪个；点其它轮横条只开那一轮的，互不混叠。

先别动

  • 不动文件查看器本体、tab 去重逻辑、AppShell/ChatWindow 的接线程（已够用）。
  • 不动 HTML 预览的 sandbox / 执行脚本能力。
  • 不做「会话级累计汇总 / 全部自动开」（你已明确“不累计”）。

未知与假设

  • 假设（改动A）：注入用低优先级选择器，文件自带样式优先；带完整 html/body 背景色的 HTML 保持自身样式，只有空白背景/未定色的才跟随主题。极端自定义样式可能不完全跟随，属预期。
  • 假设（改动B）：同一轮产物之间路径不重复（提取层已去重）；点某个 chip 时以「该 chip 对应文件」作为激活页。
  • 材料：够——FileViewer.tsx 预览 iframe、useTheme().isDark、ArtifactStrip.tsx、AppShell.handleOpenFile（多标签去重）均已核实。
