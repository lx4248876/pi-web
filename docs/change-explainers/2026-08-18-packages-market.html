插件市场面板（Packages）

pi-web 界面新增一个可在网页里「看到并点装即用」的 pi 插件市场，参照现有 Skills 市场。

一句话

在侧边栏底部加一个 Packages 按钮，点开弹出插件市场：列出 pi.dev 上的插件、按关键词搜索、点「Install」真实执行 pi install npm:包名（全局安装），装完立即显示「✓ Installed」。

为什么改

现状：pi-web 已有一个 Skills 市场（对接 skills.sh）。但对 pi 官方插件表（pi.dev/packages —— 面向 pi install npm:xxx 安装的包）没有对应界面。用户在网页里没法浏览/搜索/安装 pi 插件。

需求：在 web 界面里「能看到、点得到、装得上」——就是这个面板。

改动地图

主改（新建）
NEW/api/packages/route.ts
抓取 pi.dev/packages，解析包卡片为 JSON 列表（name / description / types / downloads / date / install-cmd / links）。
NEW/api/packages/install/route.ts
接收包名，跑 pi install npm:包名（全局），返回成功或错误。参照现有 skills/install。
NEWcomponents/PackagesConfig.tsx
弹窗 UI：左列表 + 右详情 + 顶部搜索框 + 安装按钮，克隆 SkillsConfig.tsx 布局与样式。
主改（接线）
components/app-shell/SidebarPanel.tsx
底部 Models / Skills 旁新增「Packages」按钮与回调占位。
components/AppShell.tsx
加 packagesConfigOpen 状态 + handleOpenPackages + 透传 onOpenPackages + 渲染 PackagesConfig。

逻辑链路

侧边栏 Packages→ AppShell.setPackagesConfigOpen(true)→ 渲染 PackagesConfig → GET /api/packages?name=关键词（实时抓 pi.dev）→ 点 Install→ POST /api/packages/install {package}→ 子进程 pi install npm:xxx（全局）→ 前端显示「✓ Installed」或错误

搜索走 pi.dev 真实的 ?name= 服务端查询（已验证可返回相关包），不是前端本地瞎过滤。

改完你应看到

  • 侧边栏底部出现第三个按钮 Packages（Models / Skills / Packages）。
  • 点开弹窗列出 pi 插件：名称、类型标签（extension/skill/theme/…）、下载量、描述、npm/GitHub 链接。
  • 输入关键词（如 hypa、telegram）实时过滤出匹配插件。
  • 点某插件「Install」真实安装到 ~/.pi/agent（全局），成功后显示「✓ Installed」。

先别动

  • 不改 Skills 现有逻辑（保留 skills.sh 那条线），两套并存。
  • 不改 Models / Git / 会话 / TopBar / RightPanel。
  • 不做 pi.dev 本地持久化缓存（每次打开实时抓取；安装状态仅本次会话内记忆）。
  • 不做卸载 / 更新 / 版本选择（本期只有浏览 + 安装）。

未知与假设

项当前假设
安装作用域全局（用户已确认），写 pi install npm:包名。
pi 可执行性假定找到 pi（node_modules/.bin/pi 或 PATH）；找不到则报清晰错误。安装走 lib/npx 同级的安全执行封装而非裸 shell。
搜索参数字段pi.dev 提单参数 ?name=（已实测返回；注意不是 ?q=）。
网络pi.dev 可达（本机已验证）。失败时接口返回友好错误而非崩溃。
